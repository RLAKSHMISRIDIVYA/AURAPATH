AuraPath Control Console Guided Tour

Welcome to the AuraPath Urban Safety Operating System simulator. This console demonstrates how our platform shifts safety from a reactive post-incident panic button to an active, preventative, multi-agent urban shield.

📱

Viewport 1: Commuter Companion App (Left)

Simulates the citizen's mobile client. It monitors heart rate spikes, step frequencies (gait DNA), ambient decibels (TFLite), and triggers dynamic BLE sanctuary check-in scans.

🖥️

Viewport 2: Municipal Digital Twin (Right)

Simulates the city command center dashboard. It renders the live tracking map, calculates the A* Safe Corridor using streetlights (UVI), coordinates patrol intercepts, and logs real-time WebSockets/MQTT packets.

🔄

Real-Time Synchronous Connection

The companion app and digital twin are dynamically linked. Telemetry changes on the phone update the command center map, agent states, and logs instantaneously.

🚀

How to Run the Simulation

Use the Scenario Replay Engine header panel. Select Case 1 or Case 2, then click "Acknowledge & Continue" to step through the commute stages and watch the system respond.

Click the Help Tour button in the header at any time to re-open this guide.
